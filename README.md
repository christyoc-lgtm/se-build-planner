# Space Engineers Build Planner

A browser-based, CAD-style ship planner for Space Engineers. Build a grid block by block in 3D and see, live:

- dry mass, cargo capacity and full-cargo mass (respecting the inventory multiplier: the game shows the full mass, but thrusters and gravity act on cargo ÷ multiplier)
- weight on any vanilla planet, or a custom gravity
- effective thrust in all six directions, scaled by air density for ion, atmospheric and prototech thrusters
- thrust-to-weight ratio and acceleration per direction, empty and full, meaning whether the ship can hold itself up with each side facing the sky
- how many more thrusters of each type you'd need to reach a target TWR (including their own mass)
- a planet-by-planet "where can it fly?" table, power draw against generation, hydrogen burn and hover time
- centre of mass, footprint and a bill of blocks

## Conveyor checks

Press **C** (or click ⛓ Conveyor view) to see the conveyor systems:

- Blocks without ports fade out, and each connected system gets its own colour.
- Port markers show large ports as big squares and small ports as small squares. They're green when connected, grey when open, amber when blocked by another block, and red where a large port meets a small one, which needs a Conveyor Converter.
- Blocks with problems get a red or orange outline.

The **Conveyor systems** panel checks that:

- every hydrogen thruster or engine reaches a hydrogen tank
- every tank reaches a Connector for refuelling
- inventory blocks are on the main cargo system
- blocks that move components (assembler, welder, grinder, connector) have a route made entirely of large conveyors

Gas, ore and ingots pass through small conveyors, but components don't. Port layouts in `js/data.js` (`PORTS`) are simplified versions of the in-game models.

## Example ships

**Examples ▾** has 12 single-propulsion ships: atmospheric, hydrogen and ion, a light and a heavy version of each, for both large and small grid, plus the two mixed-propulsion examples. They're generated by `js/examples.js`:

1. A conveyor spine is built with the cockpit, cargo, tank and connector attached through matching ports.
2. A mounting deck goes underneath: conveyor junctions on hydrogen ships, armour on the others.
3. Thrusters are added to the outer surfaces until every direction meets its target: TWR 1.6 for Up with full cargo; Forward 0.8 g, Backward 0.6 g, and Down, Left and Right 0.3 g each.
4. Batteries are added to cover the electric thrusters.

Atmospheric and hydrogen ships are sized for EarthLike, and ion ships for the Moon/space. Every example passes the conveyor checks.

## Port preview while placing

When the selected block has conveyor ports, the ghost block shows them:

- green = will connect
- white = open
- amber = blocked
- red = large/small mismatch

Free ports on nearby blocks show in blue (large) and cyan (small). The left panel lists which way each port faces in the current orientation. **T** (or the ⛓ Auto-rotate button) turns the block so that the most ports connect at the spot you're pointing at. Thrusters keep their thrust direction.

## Running it

It's a static site (HTML, CSS and ES-module JavaScript, with three.js bundled in `js/vendor`), so it needs no build step and no internet connection.

With XAMPP: start Apache and open **http://localhost/SpaceEngineersBuildTool/**

(Opening `index.html` straight from disk won't work, because browsers block ES modules on `file://`. Any local web server is fine, for example `python -m http.server`.)

Designs autosave in your browser. **Save** keeps named designs in browser storage, and **Export/Import** moves them around as `.sebp.json` files.

## Controls

| Action | Input |
|---|---|
| Place / erase / pick / paint | Left-click (tools 1–4) |
| Fill a box | Shift + left-drag with Place |
| Orbit / pan / zoom | Right-drag / middle-drag (or Shift+right) / wheel |
| Rotate block | W / S tilt front up / down · A / D turn left / right · Q / E roll left / right · X resets (R / F / V also work) |
| Build plane up/down | ] / [ (or PageUp / PageDown) |
| Conveyor view | C |
| Auto-rotate to connect ports | T |
| Undo / redo / save | Ctrl+Z / Ctrl+Y / Ctrl+S |

The ship's **Forward is −Z** (red arrow) and **Up is +Y** (green). A thruster pushes the ship away from its nozzle.

## Data

The block and thruster stats are in `js/data.js`. They come from spaceengineers.wiki.gg (block infoboxes and the Thruster Comparison table) and from 343N/spaceengineers-thrust-calc. Blocks marked ≈ use older game data and may be slightly off. You can override a block's mass, thrust or inventory per design (Pick tool, then click a block), or add modded blocks with **+ Custom**.

Thruster effectiveness against air density (0 = vacuum, 1 = Earth sea level):

- Atmospheric: 0% at 0.3 or below, rising linearly to 100% at 1.0
- Ion: 100% in vacuum, falling linearly to 20% at 1.0
- Prototech: 100% in vacuum, falling linearly to 30% at 1.0
- Hydrogen: 100% everywhere

The planet surface densities for Pertam, Mars and Alien are approximate, so use the air-density slider to model them or to model altitude.
